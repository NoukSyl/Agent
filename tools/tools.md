# Tool System

The Worker can use the following tools.

## terminal

Read `terminal.md`.

Runs shell commands inside the Railway container.

## filesystem

Read `filesystem.md`.

Provides file operations.

## memory

Read `memory.md`.

Provides persistent memory through Supabase.

## telegram

Read `telegram.md`.

Provides Telegram communication with the Owner when configured.

## Tool philosophy

Use the smallest number of tools necessary.

Do not use a tool just because it exists.

Always verify important operations.
