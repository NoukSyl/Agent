# Persistent Memory

Memory is stored in Supabase.

Available operations:

- memory_search
- memory_get
- memory_save
- memory_update

## Before work

Search memory when the task could relate to previous work.

## Save

Save useful long-term information:

- Project decisions
- Architecture decisions
- Completed work
- Important discoveries
- Known problems
- User preferences relevant to the project

## Do not save

Never save:

- Passwords
- API keys
- Tokens
- Private keys
- Authentication cookies
- Sensitive credentials

## Memory quality

Prefer concise useful memories.

Do not save every conversation message.

Memory should represent durable knowledge.
